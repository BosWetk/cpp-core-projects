# C++ Core Projects Portfolio

A collection of algorithms, data structures, and mathematical models implemented in C++. These projects demonstrate a strong foundation in computer science, memory management, and analytical problem-solving.

## Projects Overview

### 1. Graph Algorithms Visualizer
* **File:** `graph_algorithms_visualizer.cpp`
* **Description:** An interactive graphical tool built with C++ and OpenGL (freeglut) to visualize and execute fundamental graph algorithms step-by-step.
* **Algorithms:** BFS, DFS, Dijkstra, Bellman-Ford, Floyd-Warshall, Kruskal, Prim, Ford-Fulkerson, Edmonds-Karp.

### 2. High-Precision Math & Cryptography Library
* **File:** `high_precision_math.cpp`
* **Description:** A custom toolkit for handling long arithmetic and primality testing without external big-integer libraries.
* **Algorithms:** Karatsuba and Toom-Cook multiplication, Cook's division, probabilistic primality tests (Miller-Rabin, Solovay-Strassen).

### 3. Computational Geometry Tools
* **File:** `convex_hull_algorithms.cpp`
* **Description:** Implementations of algorithms for processing spatial data and finding convex hulls.
* **Algorithms:** Graham scan, QuickHull, Andrew's monotone chain, Kelly-Kirkpatrick methods.

### 4. Search and Pattern Matching
* **File:** `search_and_pattern_matching.cpp`
* **Description:** A comprehensive suite of search algorithms and sequence analysis tools.
* **Algorithms:** Landau-Vishkin (fuzzy search), Wagner-Fischer (Levenshtein distance), Binary and Interpolation search.

### 5. Random Number Generators & Distributions
* **File:** `random_number_generators.cpp`
* **Description:** Implementation of various pseudo-random number generators (PRNGs) and statistical distributions.
* **Algorithms:** Linear/Quadratic congruential methods, Arens method, Polar coordinates method.

### 6. Spatial Points Analysis
* **File:** `spatial_points_analysis.cpp`
* **Description:** Mathematical processing of 2D and 3D coordinates, including distance calculations and spatial boundaries.

## 🛠 Tech Stack
* **Language:** C++
* **Libraries:** STL, OpenGL (freeglut)
* **Concepts:** Object-Oriented Programming (OOP), Pointer Arithmetic, Data Structures, Computational Mathematics
